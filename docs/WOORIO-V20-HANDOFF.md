# 우리오 v20 구현 인수인계 — 2026-11-05

대상: Sites WoojinHub 공개 허브의 우리오 게임만. 기존 게임과 `woojin-adventure-v1` 로컬 저장 키를 보존한다.

## 변경

- 기존 스테이지 1~5 유지, 6 `폭풍의 고가`, 7 `쇠톱 공장`, 8 `공허의 성벽` 추가. 후반 스테이지에 등반 벽·높낮이가 다른 작은 발판·왕복 톱날·강화된 가시 배치, 각 세계에 테마별 미세 환경 애니메이션을 추가.
- 가시/톱날 충돌은 능력·무적 상태와 관계없이 사망. 1.05초 솟구치며 떨어지는 캐릭터 모션 뒤 0.68초 픽셀 재도전 전환, 이후 깃발/시작점 부활. 사망 중 입력과 반복 사망을 차단.
- 거대화는 붉은 상향 화살표, 불꽃은 주황 불꽃, 두부는 하얀 강아지 형태로 표현. 끝 부근 상자를 제거. 기존 말티즈 이름을 `두부`로 전면 교체.
- 주인공 검은 머리·좁은 눈·둥근 체형 부분을 픽셀로 소폭 조정. 입력 버퍼·운동 가속·코요테 타임 개선, 포인터 ID별 버튼 상태 추적. 코인 파티클 수·최대 누적 수를 제한.
- 우리오 버튼만 굵은 3px 테두리, 각진 픽셀 스타일, 뚜렷한 눌림 상태로 개편. HUD에서 비활성 능력·만료 알림·상시 팁을 제거.

## 검증 기록

- `node tests/adventure-v20.cjs` 통과: 새 3개 맵 구성, 벽/상자 비겹침, 즉사와 사망/전환/재생성, 체크포인트, 두부, 능력 만료 알림 제거, 파티클 상한.
- `node tests/adventure-unit.cjs` 통과: 기존 5개 세계의 기하학적 이동 경로와 파워 시간 테스트. 이 단순 주행 테스트는 **치명적 가시·적을 제외하고** 맵 길과 점프 가능성만 확인하므로 실전 난이도 검증이 아니다.
- JS 문법 검사와 공통 UI 테스트 통과. 브라우저 기반 로컬 테스트의 `/usr/bin/chromium` 부재는 테스트 인프라 제한이며 실행 결과를 통과로 간주하지 않는다.
- 아직 확인할 것: 휴대폰 멀티터치와 FPS/프레임타임, 8개 세계의 실제 전투 포함 완주 가능성 및 고난도 밸런스, 아이템 분류 가시성, 짧은 전환의 저사양 기기 동작.

## 후속 개선

우선 터치 실기기 검증과 가시 위치·톱날 타이밍에 대한 플레이테스트를 진행한다. 막히는 지점을 구체적인 좌표로 재현한 뒤 필요한 구간만 수정한다. 기존 스테이지와 저장 키는 변경하지 않는다.
