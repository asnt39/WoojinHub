# 우리오 v21 게임플레이·디자인 작업 인계

작성: 2026-11-05 (KST)

## 발견한 원인

- v20 신규 스테이지 6~8에서는 `draw()`의 장식 팔레트가 5개 스테이지까지만 존재했다. 6~8번째 스테이지의 장식 렌더링 중 `color[0]` 접근이 예외를 발생시켜 캐릭터와 적이 그려지지 않았다.
- 기존 적 배치는 벽돌이 있는 구간에서 적을 모두 생략할 수 있었다.
- 초기 지형은 사실상 같은 높이의 바닥 위에 장식적인 블록만 추가되는 구조였다.

## 바뀐 내용

- 모든 8개 스테이지에 높낮이 있는 지면, 건널 수 있는 구덩이, 한 칸씩 밟고 올라갈 수 있는 계단식 벽돌을 배치했다.
- 후반 세 스테이지에 벽·발판·톱날·가시·적을 추가했다. 장식 팔레트 예외와 적 배치 충돌을 고쳤다.
- 가시는 일반 상태에서 즉사하며 거대화 상태에서는 접촉 시 파괴된다. 구덩이 추락 시 우진이가 한 번 위로 튀어 오르는 사망 모션 뒤 전환된다.
- 사망 후 미사용 상태로 복귀해야 하는 모든 보상 상자, 가시, 아이템, 보스 전용 아이템·체력·투사체를 초기화한다.
- 두부를 다시 획득하면 황금 두부가 되고 코인 수집 범위가 늘어난다.
- 8스테이지에 전용 보스와 체력 표시, 재생성되는 왕관탄 획득 아이템, 보스 공격, 보스 격파 전 출구 잠금, 격파 후 스테이지 클리어를 구현했다.
- 터치 버튼을 픽셀 스타일의 입체 버튼으로 다듬고, 다중 터치 입력 상태를 버튼에 표시하며 취소·일시정지·화면 전환 시 원래 상태로 복구한다.

## 검증 결과

- `node --test tests/adventure-v21.cjs tests/adventure-unit.cjs tests/adventure-v20.cjs`: 통과.
- 기존 테스트의 단순한 직선 달리기 자동화 대신 모든 스테이지의 구덩이를 실제 점프 물리로 통과할 수 있는지 확인했다.
- 로컬 미리보기 브라우저에서 스테이지 1·6·8의 캐릭터, 적, 장식, 벽돌 렌더링을 육안 확인했다. 이전의 배경만 나오는 오류는 해당 화면에서 재현되지 않았다.

## 추가 점검 필요

- 물리 기반 테스트는 모든 적·톱날·아이템·전투를 순차 클리어하는 완전한 게임 플레이 AI 검증은 아니다. 후반 3개 스테이지는 사람의 실제 플레이로 난도와 공정성을 추가 조정해야 한다.
- 저사양 Android 기기에서 터치 반응과 프레임 타임을 실제 프로파일링한 결과는 아직 없다.
- 공개 사이트 배포 상태와 소스 체크포인트를 각각 확인하고, 승인이 필요한 배포는 별도로 진행한다.
