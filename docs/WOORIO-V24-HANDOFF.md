# 우리오 v24 — 9스테이지·능력·기믹·3보스

기준: 2026-11-05. 변경 범위는 `dist/adventure.js`, `dist/adventure.html`, `dist/adventure.css` 및 우리오 테스트만 포함한다. WoojinHub의 다른 게임과 `woojin-adventure-v1` 저장 키는 유지한다.

## 기능

- **9개 스테이지**: 최종 `절망의 끝`을 추가하고 3·6·9스테이지에 서로 다른 보스(석상 수호자/기계 군주/그림자 우진)를 배치. 보스 직전 독립 체크포인트·안전한 부활 좌표·전용 충전탄이 있고, 보스 HP가 0이어야 골인할 수 있다. 각 보스는 체력·속도·발사 형태가 다르다.
- **신규 능력**: 날개신발은 5초간 한 번의 공중 추가 점프, 수호방패는 8초간 일반 피격 한 번 방어. 기존 거대화·파이어볼 5초, 파이어볼 비행 지속을 0.85초에서 0.97초로 소폭 늘렸다. 능력 시간은 짧은 게이지로 표시한다. 가시/낭떠러지는 일반 캐릭터에게 계속 즉사이며, 거대화는 가시를 부순다.
- **새 구조물**: 1부터 스프링, 2부터 무너지는 발판, 3부터 승강 발판, 4부터 컨베이어, 5부터 시간제 스위치/문을 점진적으로 등장시켰다. 보스마다 전용 아레나와 공중 발판을 배치했다. 좁은 발판 옆 절벽에 높은 벽이 가로막는 문제도 조정했다.
- **새 적**: 그림자 박쥐(움직임/비행), 감시 포탑(조준탄). 기존 적에 더해 작동하고, 사망 후 적의 생존·체력·위치·공격 타이머가 초기화된다.
- **고정형 럭키박스**: 상자 좌표와 스테이지로 아이템을 결정한다. 사망 후 상자와 보상은 같은 상태로 초기화되고, 종류는 변하지 않는다. 기존 두부/황금 두부 유지, 두부의 일반 적 추적 거리 75→55픽셀(황금 65픽셀).
- **UI**: 아이템을 픽셀 아이콘으로 구분하고, 발판·게이트·몬스터·보스별 색상과 형태를 구분. 모바일 버튼 입력 상태와 능력 게이지를 개선했다. 별도의 이미지 생성/외부 그래픽은 아직 적용하지 않았다.
