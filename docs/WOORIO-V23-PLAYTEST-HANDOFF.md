# 우리오 v23: 실제 입력 AI 경로 테스트·공중 발판 판정

기준: 2026-11-05, WoojinHub Sites 메인 브랜치. 기존 세이브 키 `woojin-adventure-v1`은 변경하지 않는다.

## 확인된 문제와 수정

- 일부 낭떠러지 옆에 있는 `ledge` 발판을 점프하는 도중 옆에서 들이받으면 캐릭터가 공중에 걸려 추락했다. 1스테이지 7번째 낭떠러지(`x=4100..4182`)에서 실제 물리 입력으로 재현했다.
- 공중 `ledge`는 **위에서 하강할 때만 착지**하는 일방향 발판으로 변경했다. 좌우 측면 및 밑면에서 이동·점프를 막지 않는다. 일반 벽돌, 럭키박스, 지면, 높은 벽, 가시·톱날 판정은 그대로다.
- `tests/adventure-ai-jump-reachability.cjs`: 8개 스테이지의 114개 낭떠러지마다 실제 `key`와 `tick`으로 점프·착지 가능한 발사 지점을 탐색했다. `start` 후 영웅을 지역 출발 지점에 배치하는 **격리 구간 테스트**이며, 도중 적과 위험물은 제거하지 않는다. 일부 고난도 지역은 높은 벽돌·발판 위에서 출발해야 통과한다. **게임 시작부터 연속으로 올라갈 수 있는지는 보증하지 않는다.** 결과 114/114.
- `tests/adventure-ai-playthrough.cjs`: 캐릭터 좌표·장애물·보스 HP를 변경하거나 텔레포트하지 않고, `start`, `key`, `tick`만으로 전체 진행을 시도하는 반응형 조작기. 다섯 가지 점프 타이밍 설정으로 8개 스테이지를 각각 독립 시험, 각 4회 사망까지. 완주 **0/8**. 기초 AI가 가시·적·복합 발판 타이밍을 못 맞춘 사례이며, 이것만으로 맵이 불가능하다고 결론지을 수 없다. 최종 보스 실전 격파도 **미검증**.

## 검증과 미검증

- 통과: `adventure-unit.cjs`, `adventure-v20.cjs`, `adventure-v21.cjs`, `adventure-v22.cjs`, `adventure-ai-jump-reachability.cjs`.
- 의도된 비통과/진단 전용: `adventure-ai-playthrough.cjs`는 0/8 종료 코드 1을 내며, 완주 검증으로 오인하면 안 된다.
- `tests/adventure.cjs`의 실제 Chromium 브라우저 구동: 실행 환경에 `/usr/bin/chromium`이 없어 시작 실패. 실제 스마트폰 멀티터치·프레임 안정성·화질·실제 사람의 8스테이지 연속 클리어는 미검증.

3. Chromium과 실제 모바일에서 점프가 공중 발판을 자연스럽게 통과하는지 수동 검사한다.
