# 우리오 정밀 조작·하드 스테이지 디자인 (2026-11-05)

## 의도

기존 WoojinHub의 5개 우리오 스테이지와 저장 진행을 보존하면서 플랫폼 액션의 긴장감, 캐릭터성, 터치 조작 반응을 높인다. 다른 세 게임과 허브는 변경하지 않는다.

## 확정 요구

- 가시와 새로운 치명적 장애물에 닿으면 능력에 관계없이 사망한다.
- 사망 시 우진 픽셀 캐릭터가 위로 솟았다가 떨어지는 연출과 짧은 화면 전환 후 체크포인트/시작점에서 재개한다.
- 기존 5개 맵에 등반·동적 플랫폼 구간을 보완하고, 뒤에 초고난도 맵 3개를 이어 붙인다. 어려워도 물리적으로 완주 가능한 경로를 둔다.
- 불꽃과 거대화 아이템을 색상과 실루엣으로 즉시 구별하고, 골인 직전 보상 상자를 배제한다. 말티즈의 이름은 '두부'로 한다.
- 우진 캐릭터는 풍성한 검은 머리, 실눈, 약간 둥근 배라는 이미 확정된 특징을 작은 픽셀 수정으로 강화한다.
- 점프 입력 버퍼·코요테 타임·손가락별 포인터를 개선한다. 반복 DOM·Canvas 비용을 불필요하게 늘리지 않고, 실기기 FPS는 별도 검증한다.
- 화면에는 필요한 스테이지/코인/활성 능력만 표시하고 능력 만료 공지는 제거한다. 명확한 픽셀 버튼을 제공한다.

## 구현 대안과 선택

1. 기존 생성형 레벨에 난이도 규칙과 동적 장애물을 추가 (선택): 저장 형식·코드 변경량이 작고 기존 맵을 유지한다.
2. 새 레벨 에디터·JSON 파이프라인 전면 개편: 장기 확장성은 높지만 이번 속도·안정성 목표에는 과하다.
3. 별도 하드 모드 분리: 기존 진척과 UX가 분리돼 현재 요청의 '새 맵'과 맞지 않는다.

## 성공 기준과 위험

- 기존 5개 세계 진척이 유지되고 새 세계는 이전 세계 클리어로 해금된다.
- 치명적 충돌은 즉시 사망 상태가 되고 짧은 애니메이션 동안 연속 사망·아이템 획득이 불가능하다.
- 총 8개 스테이지, 새 스테이지에 고저차·정밀 점프·동적 장애물, 단순 자동 주행으로는 완주하기 어렵다.
- 빠른 입력/동시 터치/일시정지/숨김 전환 시 눌림 상태가 남지 않는다.
- 모든 게임 모드 저장 키와 기존 스테이지 번호는 유지한다.
- 자동 테스트와 브라우저 확인은 가능하지만 실제 안드로이드 기기 FPS/멀티터치 결과를 속단하지 않는다.
